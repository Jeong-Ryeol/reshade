# Sherbet

리쉐이드를 베이스로 처음부터 다시 만든 개인 커스텀 클라이언트입니다.
프리셋 파일만 얹어서 파는 게 아니라, 설정을 받아서 전용 fx 셰이더를 만들고
클라이언트 자체를 C++로 직접 빌드해서 드려요. 그래서 같은 빌드가 두 개 존재하지 않습니다.

문의는 디스코드 티켓으로 받고 있어요 — discord.gg/5NGR7XVFta

---

## UI

기본 리쉐이드 특유의 회색 창을 바닥부터 갈아엎었습니다.

- 게임 화면을 다 가리는 전체창이 아니라, 옮기고 크기 조절되는 카드형 창
- 창 안에서 테마 색이 은은하게 흐르고, 테마마다 다른 파티클이 떠다닙니다 (하트, 잎사귀, 반짝이)
- 한글은 주아체, 영문이랑 숫자는 Fredoka로 통일했습니다. FPS 숫자까지 다 둥글둥글해요

## 테마

전부 7종이고, 기본 1개가 포함됩니다. 나머지는 언락코드로 열 수 있어요.
인게임 마켓 탭에서 코드 입력하면 바로 적용됩니다.

| 테마 | 느낌 |
|---|---|
| Mint Soda | 청량한 민트 |
| Peach Punch | 따뜻한 피치 |
| Pink Crush | 진한 핑크 |
| Prism Pop | 색이 계속 순환하는 레인보우 |
| Lavender Dream | 몽환적인 라벤더 |
| Noir Gold | 블랙 + 골드 |
| Strawberry Milk | 흰 우유에 딸기 떨어뜨린 라이트 테마 |

## 반반 비교

버튼 하나 누르면 화면이 반으로 갈라집니다.
왼쪽이 원본, 오른쪽이 보정본이고 가운데 선을 마우스로 끌면 비율이 움직여요.
내 색감이 실제로 뭘 바꾸고 있는지 눈으로 바로 확인할 수 있습니다.

## 커스텀 조준점

조준점 이미지를 직접 넣을 수 있습니다.

- 폴더에 PNG 넣으면 목록에 떠서 고르면 끝
- 이미지 없어도 내장 도형 4종 (점, 십자, 원, 십자+점)
- 크기, 두께, 색, 투명도, 위치 전부 조절 가능하고 설정은 저장됩니다

## 편의 기능

- 스크린샷, 성능 모드, 다시 로드가 상단 버튼 하나씩
- 자주 쓰는 이펙트는 우클릭으로 즐겨찾기 등록, 필터로 바로 걸러볼 수 있어요
- 프리셋 여러 개 쓰면 화살표로 넘기면 됩니다
- FPS 표시는 드래그해서 아무 데나 둘 수 있어요

## 개인 프리셋 내장

주문할 때 만든 맞춤 프리셋이 빌드 안에 들어갑니다.
파일 잃어버려도 마켓에서 원클릭으로 복원돼요. 10초 체험으로 미리 볼 수 있고, 전용 코드로 정식 해제하는 방식입니다.

## 각인

- 게임 켜면 스플래시에 "OOO님을 위한 커스텀"
- 정보 탭에 등록 소유자랑 주문번호가 새겨집니다

## 보호

- 원하시면 처음 실행한 PC에서만 열리게 잠글 수 있습니다. 파일이 밖으로 나가도 다른 컴퓨터에선 안 열려요
- 언락 상태는 설정 파일을 손으로 고쳐도 안 풀립니다. 정식 코드만 인정돼요

## 가격

| 상품 | 가격 |
|---|---|
| 커스텀 개인 리쉐이드 빌드 | 1000 |
| 커스텀 색감 개별 수정 | +1500 |
| 테마 추가 (개당) | +600 |
| 기존 설정 유지, 커스텀 FX 파일만 제작 | 400 |

리쉐이드 파일 불러와서 딸깍딸깍 하는 게 아니라 설정 파일 받아서 fx 제작부터
클라이언트 빌드까지 직접 개발합니다. 그래서 제작 시간은 OOC 사정에 따라 달라져요.

## 구매 전에 확인해 주세요

- 서버나 게임에 따라 오버레이를 안티치트가 막을 수 있습니다. 사용 가능 여부는 본인이 확인해 주세요. 조준점 기능은 특히 주의
- 인게임 폰 카메라 사진에는 리쉐이드가 안 담깁니다. 게임 구조상 그렇습니다. 보정된 사진은 내장 스크린샷 버튼으로 찍으면 돼요
- 개인 제작 상품이라 파일 전달 후 단순 변심 환불은 어렵습니다
- 재배포, 공유 금지. 적발 시 지원이 중단됩니다
- PC 바꾸시면 티켓 주세요. 재발급 도와드립니다
